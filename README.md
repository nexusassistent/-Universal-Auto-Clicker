# 🖱️ Universal Auto-Clicker

Современный, автономный и функциональный автокликер с неоновым киберпанк-интерфейсом. Позволяет автоматизировать нажатия мыши и клавиатуры с гибкой настройкой параметров.

> ⚠️ **Дисклеймер:** Автор не несет ответственности за использование программы в онлайн-играх или приложениях, где это нарушает правила использования (ToS). Используйте на свой страх и риск.
> 
> 🛡️ **Примечание об антивирусах:** Из-за использования системных API (`SendInput`, глобальные хуки) для работы горячих клавиш, некоторые антивирусы могут ложно определять программу как подозрительную. Это стандартное поведение для утилит автоматизации. Программа безопасна.

## ⚡ Возможности

- 🚀 **Портативность:** Работает из одного `.exe` файла без установки .NET Framework и дополнительных зависимостей. (Скачал и запустил!)
- 🐭 **Мышь:** Выбор кнопки (ЛКМ, ПКМ, СКМ), режимы клика/удержания, точная настройка CPS или задержки, лимит кликов.
- ⌨️ **Клавиатура:** Захват любой клавиши, поддержка модификаторов (Shift, Ctrl, Alt, Win), настройка скорости и лимита.
-  **Интерфейс:** 3 темы (Киберпанк, Тёмная, Светлая) и полная поддержка Русского / English языков.
- 💾 **Удобство:** Автосохранение настроек, сворачивание в трей, глобальные горячие клавиши (работают даже в свернутом состоянии).

## ️ Горячие клавиши по умолчанию
- **F1** — Старт/Стоп автокликера мыши (на вкладке Мыши).
- **F2** — Старт/Стоп автонажатия клавиш (на вкладке Клавиатуры).

## 🛠️ Технологии
- C# / .NET (WPF)
- Windows API (`SendInput`, `SetWindowsHookEx`)
- Newtonsoft.Json (для сохранения настроек)
